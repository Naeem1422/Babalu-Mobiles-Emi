# Babalu Mobiles & Electronics — Customer EMI Form

This repository contains the HTML customer EMI form.

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html` and `README.md` to the repository's main branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then press **Save**.
6. Wait for GitHub Pages to publish the website. Open the URL shown in **Settings → Pages**.

## Important
- The product barcode scanner needs a supported browser and camera permission. Camera access generally requires HTTPS, such as GitHub Pages.
- Customer information entered in the form is processed in the browser by this HTML file. Do not upload real customer applications, ID photos, or personal data to a public repository.
- This is a form/calculator, not a regulated finance-provider service. Review the form, fee rules, and legal requirements before using it with customers.
